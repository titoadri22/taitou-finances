📱 Atajos iOS

Registra gastos desde el Centro de Control de tu iPhone

⚡

¿Cómo funciona?

Crea un token API y configura un Atajo de iOS para registrar gastos e ingresos directamente desde el Centro de Control de tu iPhone, sin abrir la app. El flujo te preguntará el tipo, monto, descripción y categoría, igual que en el video.

1. Crea un token 2. Copia el token 3. Configura el Atajo

🔑 Tokens API

🔐

No tienes tokens creados

Crea uno para empezar a usar los atajos

📖 Guía de configuración

1

Crear el Atajo en tu iPhone

Abre la app Atajos de Apple → toca + → dale nombre: "Registrar gasto"

2

Añadir acción "Elegir en menú"

Busca "Elegir en menú" y añade dos opciones: "Gasto único" y "Pago recurrente"

3

Para "Gasto único"

Añade estos pasos:
• Solicitar entrada → "¿Cuánto gastaste?" (tipo: Número)
• Solicitar entrada → "¿En qué lo gastaste?" (tipo: Texto)
• Elegir en lista → Tus categorías (Comida, Transporte, etc.)
• Obtener contenido de URL → método POST a tu API

4

Configurar la llamada API

URL: cargando...
Método: POST
Headers: Authorization: Bearer TU_TOKEN
Body (JSON): 

{
  "type": "expense",
  "amount": [Monto solicitado],
  "description": [Texto solicitado],
  "category_name": [Categoría elegida]
}
5

Añadir al Centro de Control

Ve a Ajustes → Centro de Control → añade un control de Atajos y selecciona tu atajo "Registrar gasto"

🔧 Referencia API

GET /shortcuts/categories?type=expense

Lista tus categorías (para menú del Atajo)

GET /shortcuts/accounts

Lista tus cuentas

POST /shortcuts/transaction

Registrar gasto o ingreso: { type, amount, description, category_name }

GET /shortcuts/balance

Resumen del mes: ingresos, gastos y saldo por cuenta
